# Локальная витрина

Запустите сборку из корня проекта.

```powershell
docker compose up --build --wait app
```

Откройте [витрину](http://localhost:8080/). При первом запуске Docker импортирует комплектный демокаталог из 35 предложений. Существующий активный снимок сохраняется. Чтобы работать со своей XML-выгрузкой, выполните штатный импорт. Отключить автоматический импорт демоданных можно переменной `SEED_DEMO_CATALOG=false`. [Импорт каталога](../README.md#поиск-по-каталогу-softline)

Каталог, поиск, подсказки, чат и аналитика используют локальные маршруты Spring. Изображение-заглушка, логотип и шрифты входят в сборку. Пробный заказ оформляется в интерфейсе витрины. Чат хранит до трёх диалогов в браузере семь дней.

- На главной есть десять запросов из [таблицы задания](../supplementary/SearchQueries.xlsx).
- Каталог без строки поиска загружает по восемь карточек, использует серверную сортировку, фильтры и страницы.
- Поиск отображает до 50 результатов ответа API по четыре на страницу. Номер страницы, запрос, выбранная подсказка, сортировка и фильтры сохраняются в адресе.

## Проверка

```powershell
python backend/acceptance/storefront_smoke.py http://localhost:8080 --requests 360 --workers 16
```

Проверка рассчитана на комплектный демокаталог и запускается только на loopback. Она сверяет эталонные запросы, пагинацию без повторов, порядок цен, комбинации фильтров, пустую выдачу и ответы чата. Нагрузочный прогон смешивает каталог, поиск, подсказки и карточки товаров.
