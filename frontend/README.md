# Витрина Softline Store

На страницах сохранены разметка, стили, иконки и ссылки публичной витрины Softline Store от 27 ноября 2026 года. Часть изображений загружается с исходного CDN. Скрипт `public/softline-ui.js` открывает меню, переключает баннеры, обрабатывает вкладки и подключает поиск и чат к Spring.

## Запуск

Из корня проекта, на чистых томах Docker.

```powershell
docker compose build app
$feed = (Resolve-Path 'backend/src/main/resources/search/demo.xml').Path
docker compose run --rm --no-deps --volume "${feed}:/catalog.xml:ro" app import
docker compose up -d --wait app
```

Витрина открывается на [localhost:8080](http://localhost:8080/). Для полного каталога используйте командную XML-выгрузку по [инструкции проекта](../README.md#поиск-по-каталогу-softline).

## Страницы и API

- Главная, каталог, основные разделы верхнего меню, производители, акции и подборка «Кибер Бэкап».
- Карточки Microsoft Office EP2-06605 и Pantum P2500W, пустые страницы сравнения и избранного.
- Поиск использует `GET /v1/suggest` и `POST /v1/search`. Фильтры по категориям и производителям строятся по фасетам ответа. Сортировка передаётся полем `sort`.
- Чат передаёт вопрос и контекст в `POST /v1/search` с `strategy: "llm"`. История хранится в браузере до семи дней, отображаются три последних чата.

Остальные ссылки открывают соответствующие страницы Softline. Вход, корзина, оформление заказа, подписка и динамические подборки магазина требуют его серверной реализации. Сохранённые формы не передают данные магазину. Выдача поиска и чат работают с данными конкурсного приложения.

## Обновление снимков

Для повторной загрузки нужны Python 3, `lxml` и `curl`. Каталог кэша передаётся отдельным аргументом и может находиться вне репозитория. Для полной перезагрузки укажите пустой каталог.

```powershell
python frontend/capture_storefront.py "$env:TEMP/softline-public-capture"
```
